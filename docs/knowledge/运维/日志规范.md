# 日志规范

## 日志级别

- DEBUG：开发调试使用，生产环境禁止开启。
- INFO：记录正常业务流程，如登录、下单、任务完成。
- WARN：潜在风险但不影响主流程，如重试、限流触发。
- ERROR：异常与故障，必须记录堆栈与上下文参数。

## 日志格式

统一使用 JSON 格式输出，必含字段：time、level、service、message、traceId。traceId 由网关生成并在整条调用链透传。

## 日志存储与保留

- 日志写入按天滚动文件，保留 30 天。
- ERROR 级别日志同步上报到日志中心（Loki），用于告警。
- 严禁在日志中输出用户密码、Token、身份证号等敏感信息，脱敏后方可记录。

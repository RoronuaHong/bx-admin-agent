# 部署规范

## 服务托管方式

- 前端项目（next dev / next start）用 PM2 托管，进程名见各项目 ecosystem.config。
- 后台管理项目（docker-compose 编排）由 Docker 托管，restart:unless-stopped。
- 改源码后重新构建并重启：docker compose up -d --build --no-deps <服务名>。

## 端口约定

- 前端开发端口 5173/5174。
- backend 服务端口 8001（容器内 8000）。
- 修改端口后需同步更新环境变量与反代配置。

## 重启注意事项

- pm2 restart 前确认无冲突进程（避免端口竞争 EADDRINUSE）。
- 重启后验证健康检查接口返回正常再继续后续操作。

② 跨轮熔断

③ Gate 门禁

B · 协议护栏 服务端唯一判定（非语义） 全部基于结构 / 契约 / 数量，零业务词
B1 伪调用协议检测
  • isToolPlanText / validateFinalText
  • 识别文本模拟工具调用（JSON / XML / 方括号 / action 键）
  • 工具名 = AGENT_TOOL_NAMES 英文契约，零中文 / 零功能词
B2 同轮重复去重
  • callApiKey = operation | path | JSON(params)
  • 同轮全等 → 合并执行第一个
  • 其余注 [workflow/observe] 引导模型基于分页信息递增
B3 Gate 可调用性门禁
  • rulesGateBeforeCallApi 模块可调用性校验
  • 歧义 / 不可调用 → MODULE_RETRY 回喂模型自愈
  • 缺槽位 → CLARIFICATION_REQUIRED 澄清
B4 数量护栏
  • understandAttempts 首轮理解重试 ≤ 3（仅首轮 +1；工具执行后续探轮不消耗，对齐 Cursor 循环语义）
  • MAX_TOOL_ROUNDS 工具轮次上限（=14）
  • recursionLimit LangGraph 递归上限（兜底）
C · 确定性兜底 弱模型 / 异常保护 → 泳道 D 服务端规则编排，不给模型无限空转
C1 伪调用耗尽
  • pseudoPlanExhausted：伪调用连续 3 次（understandAttempts ≥ 2）→ 强制 final
  • → 泳道 D 规则编排拿真实数据
C2 跨轮 Doom Loop 熔断
  • TOOL_SIGNATURE = name | operation | path | JSON(params)
  • 同一工具 + 同一入参连续 ≥3 次 → doomLoopExhausted → 强制 final
  • 正确递增分页（page:1→2→3）签名不同不触发；与 B2 双层互补
C3 模型调用失败
  • 402 / 401008 → 如实抛错（不静默降级）+ 封禁 30min
  • 429 / 503 / 504001 → 瞬时重试 2 次（退避 3s / 6s）
C4 导出意图兜底
  • 用户要导出 / 下载 + lastTable 有数据 + 模型未走 export_dataset
  • → 服务端自动 execExportDataset 生成 xlsx / pdf + 预览上屏
C5 模型级门槛
  • MODEL_<ID>_AGENT=false → 不进多轮工具循环
  • 一次模型调用纯问答（tools=[]，带 staticGuide 前缀）
  • 弱模型只开放普通对话，不进多轮工具循环
D · 规则编排兜底 runServerFallback · 确定性路径 C1 / C2 熔断、写意图或模型未取数时的服务端兜底（Graph 之外）
D1
触发条件
businessToolCalled=false / pseudoPlanExhausted / doomLoopExhausted / writeForce（模型信号驱动，无中文预判）
D2
写操作确认门
writeForce → confirmation_required + waitForConfirmation 阻塞；取消则如实返回「未执行」
D3
规则选路
resolveApiOperation / resolveModuleDetail / listPriority（英文 CRUD 契约词）；不命中 → 澄清
D4
执行 + 受控渲染
call_api 真实请求 → renderListForAgent / renderDetailForAgent（中文列 + 枚举翻译）→ UI_TABLE 上屏 + 写 lastTable
D5
澄清或收束
缺槽位 → CLARIFICATION_REQUIRED 渲染成友好问题；成功 → text 收束 + push assistant 历史
E · 会话与数据层 session.ts · 跨请求状态底座 graph 不跨请求，跨轮上下文全靠 session 持久化（用户可见历史 ≠ 模型实际 token）
E1 会话载体
  • token / country / menus（登录态）
  • messages（完整历史，持久化到磁盘）
  • TTL 过期回收
E2 历史分层压缩
  • buildModelTurns：full → prune（表格折叠 / 超长截断，零模型调用）→ LLM 摘要（tools=[]）
  • 缓存 historyCompact{summary, coveredIndex} 跨轮复用
  • 模型只见「摘要块 + 预算内历史」只读投影
E3 最近表格缓存
  • lastTable{title, columns, rows, total, at}
  • 导出延续场景数据源（A4 ④ / C4 自动导出）
E4 挂起澄清
  • pendingClarification 存选项 / 轮次
  • 下一轮用户回序号 → 直读收束（A0 挂起澄清直读）
架构原则：语义判定 100% 交大模型（业务 / 闲聊 / 意图 / 模块 / 分页 / 参数 / 输出格式）；服务端仅承担协议护栏（B1-B4）、数量护栏（understandAttempts / MAX_TOOL_ROUNDS / Doom Loop 熔断）、受控渲染（PC 列定义 + 源码枚举）、确定性兜底（C1-C5 → D1-D5）。静态引导前缀化（system 稳定前缀 → Prompt Cache）；模型级门槛（agentCapable，弱模型只开放普通对话）。跨请求上下文靠 session 持久化（E1-E4），graph 不跨请求。工具名 / 分类 / 协议全部从注册表派生，零业务词写死。

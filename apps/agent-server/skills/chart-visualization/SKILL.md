# 图表出图流程

适用场景：用户要求「画个图」「可视化」「饼图/柱状图/折线图/趋势/占比」。

## 步骤

1. **先取数，再出图**：先调用数据工具（BI 查询等）拿到真实数据，再调用图表工具（`mcp__chart__generate_*`）。**禁止编造数据点**——图里的每个数值都必须来自工具真实返回。
2. **只画聚合后的序列**：建议 ≤50 个数据点，先在查询侧聚合好维度与指标，不要把明细行塞进图。
3. **选图型**：占比 → 饼图；对比 → 柱状图；趋势 → 折线/面积；层级/结构 → 树图/思维导图；关系 → 桑基/网络图。拿不准时柱状图最稳。
4. **贴图进回复**：出图工具返回图片 URL 后，**必须用 `![标题](url)` Markdown 图片语法贴进回复正文**，不要只给一个裸链接。
5. **附数据摘要**：图下方用一两句话复述出图用的数据来源与关键数字（工具名 + 关键参数 + 数值），便于核对图与数一致。

## 注意

- 图表工具会把查询结果数据发送到外部渲染服务（每次调用前会弹确认卡，这是数据外发的显式确认）。
- 返回的是图片 URL 而非图本身：确认卡上的参数摘要就是将送去渲染的数据，批准前可核对。
- 无法从工具拿到真实数据时，如实说明并给出取数建议，不要用编造数据出图。

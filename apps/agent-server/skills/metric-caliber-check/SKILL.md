# 指标口径核对流程

适用场景：用户问「这个指标是怎么算的」「两个数对不上」「口径是不是一样」。

## 步骤

1. **先列口径假设**：明确指标名、时间粒度、时间范围、去重口径、过滤条件。
2. **查定义**：用 BI 元数据工具（list_cards / get_card）取该指标的 SQL 与描述，不要凭记忆回答。
3. **对照比较**：如果存在两个来源（如图表 vs 报表），逐项对比 SQL 里的过滤条件与聚合方式，列出差异点。
4. **抽样验证**：必要时用 run_native_query 跑最小验证 SQL（加 LIMIT），确认差异方向。
5. **给出结论**：说明「口径差异在哪一句 SQL / 哪个过滤条件」，而不是只说"数据不同"。

## 输出格式

- 结论一句话；
- 差异点列表（来源 A vs 来源 B）；
- 验证 SQL 与关键返回值。

## 注意

- 中间过程不要贴整段 SQL 结果，只给关键行。
- 无法确认的口径差异要明说，不要猜。
- 字段 / 表语义本身不确定时（取值域、主键、表关系），先按 `schema-probe` 技能取证，再谈口径差异。

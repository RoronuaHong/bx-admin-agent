# 写操作确认

用户要改数据（增删改、上下架、审核、开关、批量）时使用。

## 流程

1. 检索确认 operation（`search_api_module` / `read_api_module`）
2. `call_api` 时 **`confirm=true`**，description 写清业务含义与影响对象
3. 成功后尽量回读详情（或再次 list）确认结果
4. 用中文简短说明「已完成什么 / 当前状态」

## 强制

- 未确认不得执行写接口。
- 批量操作说明影响范围（条数/筛选条件）。

## 禁止

- 把写操作伪装成查询。
- 审核类操作省略「通过/驳回」结果反馈。
